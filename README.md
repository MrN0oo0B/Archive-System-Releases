### ✨ Key Features

* **Modern RTL/LTR Interface:** Clean UI with full support for Arabic & English languages.
* **Advanced Document Management:** Fast organization, indexing, and document retrieval.
* **Role-Based Access Control:** Define permission levels for Admins, Operators, and Viewers.
* **Automated Data Backup:** Protect your documents with scheduled local back-ups.
* **Export & Print Engine:** One-click document printing and fast export to PDF and Excel (XLSX).
* **Offline Functionality:** Works 100% locally without requiring an active internet connection.

---

### 💻 System Requirements

* **Operating System:** Windows 10 / 11 (64-bit)
* **Processor:** Intel Core i3 (or equivalent)
* **Memory (RAM):** 4 GB minimum (8 GB recommended)
* **Storage:** 500 MB for installation + space for stored archives

---

### ⚡ Installation Guide

The system includes an automated installer (`Setup.exe`):

1. Download the installation package (`ArchiveSystem-Setup.exe`).
2. Double-click the file and follow the installation wizard (`Next` -> `Next` -> `Install`).
3. Once completed, a shortcut icon will appear on your **Desktop**.
4. Launch the application and sign in using the default admin credentials.
