## 🇬🇧 English

**Archive System** is a Windows desktop document archiving application for organizing, indexing, searching, previewing, printing, and securely storing incoming and outgoing official documents.

### 📦 Current Release

**v2.2.21**

The public release repository contains the Windows distribution packages and release information.

### ✨ Key Features

- Modern Arabic RTL and English LTR interface.
- Incoming and outgoing document archiving.
- Document numbering, title, date, classification, status, and metadata management.
- Advanced search and filtering.
- Document and attachment preview, download, printing, and export.
- PDF and image attachment support.
- Role-based access and account management.
- Audit and activity logging.
- Automatic local backup and restore tools.
- Data-integrity checking.
- Offline-first operation for normal document-management work.
- In-place updates designed to preserve application data.

### 💻 System Requirements

- Windows 10 / 11 (64-bit)
- x64 processor
- At least 4 GB RAM; 8 GB or more recommended
- Additional storage space for archived documents and attachments

### ⚡ Installation

1. Open the **Releases** page and download the latest Windows installer.
2. Run `Archive-System-Setup-<version>.exe`.
3. Complete the installation wizard.
4. On a fresh installation, sign in with:
   - **Username:** `manager`
   - **Temporary password:** `1234`
5. Change the temporary Manager password when prompted.

### 🔄 Updating an Existing Installation

Install the newer version normally over the existing installation.

The application is designed to preserve persistent data such as the local database, attachments, settings, users, and backups during an in-place update.

**Do not manually delete `%APPDATA%\\ArchiveSystem` before updating.**

### 🔔 Automatic Updates

Archive System uses the public release repository to detect published application updates.

For each release, the repository may contain the Windows installer and update metadata used by the application.
